On-device demo: NVIDIA Jetson edge device

LLaMA-2-7B-Chat compressed with Zero-Sum SVD, keeping about 50% of the parameters in low-rank form with a different rank for each weight matrix and 8-bit quantization, running locally on an NVIDIA Jetson edge device.

Compared with the uncompressed model:

1.30×peak speedupat 1024 input tokens
20–23%latency reductionend to end
1.31×faster per tokentime per output token
